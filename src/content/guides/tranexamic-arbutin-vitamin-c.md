faq:
  - q: 傳明酸和熊果素哪個好？
    a: 沒有一定。兩種都是衛福部核准的美白成分，上限不同（傳明酸 3%；β-熊果素 7%、α-熊果素 2%）。研究證據上，外用傳明酸針對肝斑、發炎後色素沉澱的隨機對照試驗比較多；熊果素常跟其他成分放在同一瓶。很多產品，例如 BFFECT 修修瓶，就是把兩者放在一起。
  - q: 傳明酸和維他命 C 哪個好？
    a: 2021 年一篇整理 59 篇肝斑隨機對照試驗的網絡統合分析，外用藥裡（三合一藥膏除外）外用維他命 C 排在外用傳明酸前面；但 2026 年比較「微針加傳明酸」和「微針加維他命 C」的統合分析，兩者沒有顯著差異。研究數量都不多，選哪一個更該看自己的耐受度。
  - q: 熊果素和維他命 C 可以一起用嗎？
    a: 可以。實驗室研究發現熊果素搭配維他命 C 時抑制酪胺酸酶的效果更好；市面上也有把兩者放在同一瓶的產品。分開買的話，先看各自官網的建議，刺激感大的分早晚擦。
  - q: 傳明酸和熊果素可以一起用嗎？
    a: 可以，有產品就是同一瓶，例如 BFFECT 修修瓶（官網標示 2% 傳明酸＋2% α-熊果素）。分開疊擦之前看各自官網的併用建議。
  - q: 維他命 C 白天可以擦嗎？
    a: 可以。食藥署邀請皮膚科醫師說明，「維他命 C 不能白天擦」是錯誤說法；維他命 C 有抗氧化和光保護效果，擦在防曬之前反而能增強防曬效果。擦了覺得變黑，可能是氧化變色的產品本身帶黃褐色。
  - q: 維他命 C 精華變黃還能用嗎？
    a: 食藥署的說明是不建議。維他命 C 對光線和溫度敏感，變色通常表示已經氧化，效力可能大幅降低。所以很多產品改用比較穩定的衍生物，例如抗壞血酸磷酸鎂鹽（MAP）、抗壞血酸磷酸鈉（SAP）。

## 先講共通點

衛福部核准的美白成分有十幾種，食藥署的說明是：作用分成「抑制黑色素形成」和「同時抑制黑色素形成、促進已產生的黑色素淡化」兩類。所以這三種成分處理的都是**色素斑**，不會讓天生的膚色變白，也都要搭配防曬。

食藥署也提醒：美白產品不要擦在發炎的地方；曾經過敏的人先做小範圍測試。

## 哪個比較有效？

研究沒有給出明確的贏家：

- **2021 年網絡統合分析**（59 篇肝斑隨機對照試驗）：外用藥裡，三合一藥膏最前面；其次依序是外用維他命 C、杜鵑花酸、外用傳明酸、A 酸、對苯二酚。作者也提到，維他命 C 和傳明酸的排名可能跟藥物怎麼送進皮膚有關。
- **2026 年統合分析**（微針加傳明酸 vs. 微針加維他命 C）：兩者改善肝斑的程度沒有顯著差異，研究數量不多。
- **熊果素**：常跟其他成分做成複方，單獨跟傳明酸、維他命 C 正面比較的人體研究，我們沒有查到。

所以比較實際的選法是：**挑一個你擦得住、天天會用的**。擦了刺痛泛紅，皮膚發炎反而讓斑更難處理。

## 可以一起用嗎

- **放在同一瓶**：很常見。例如 [BFFECT 修修瓶](/products/bffect-tranexamic-acid-2-whitening-serum/)官網標示 2% 傳明酸＋2% α-熊果素；三款常見淡斑精華的成分並排在[淡斑精華比較](/comparisons/dark-spot-serums-tranexamic-niacinamide/)。
- **熊果素＋維他命 C**：實驗室研究發現熊果素搭配維他命 C，抑制酪胺酸酶（黑色素生成的關鍵酵素）的效果更好。這是細胞或酵素實驗，不是人體臉上的結果。
- **分開買來疊擦**：各品牌說法不同，照你手上那一瓶的官網說明。刺激感大的（例如高濃度純維他命 C）跟其他產品分早晚擦。
- **維他命 C 和 A 醇**：食藥署邀請的皮膚科醫師建議「早 C 晚 A」分開用，減少互相干擾；孕婦、哺乳中、敏感或乾燥肌、剛做完雷射或換膚的人先暫緩。

## 怎麼挑

- **看全成分**：先確認有沒有上表裡的名字。維他命 C 寫的是衍生物還是純的 Ascorbic acid，穩定度差很多。
- **看濃度有沒有標**：寫了濃度才比得起來，對照上表看在不在法規範圍內。
- **看包裝**：純維他命 C 產品用深色、不透光的包裝比較好；變色就不要再用。
- **新手先從溫和的開始**：皮膚科醫師建議先用低刺激的維他命 C 衍生物，例如抗壞血酸葡糖苷（Ascorbyl glucoside）。

## 月奈怎麼看

成分之間的差距，常常沒有「天天擦、天天防曬」來得大。與其三瓶疊著擦，不如選一瓶擦得舒服的複方，給它 8 週。月奈正在實驗的修修瓶是傳明酸加熊果素，紀錄在[研究筆記](/lab/)。
