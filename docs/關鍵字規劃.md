# 關鍵字規劃

讀者在 Google 怎麼問，對到站上哪一頁。建議字用 `pnpm keywords <種子字>` 查（Google 搜尋建議，台灣、繁中），只代表「有人這樣搜」，沒有搜尋量；量要等 GSC 有曝光再看（`pnpm seo`）。

規則：

- **一類問題對一頁。** 標題用讀者的問法（「會消失嗎」「多少錢」「推薦」），不用站內用語。
- **想買的字（推薦、評價、比較）要有頁面接。** 通常是比較頁、品類頁、產品頁。
- **療程的字照樣做。** 彙整原理、適應症、次數、恢復期、風險、醫院公告價格與法規提醒；不推薦診所與醫師，不替讀者決定做哪一種。來源規則見 `docs/選品SOP.md`。

狀態：✅ 已有頁面、🆕 本次新增、⬜ 待做。
